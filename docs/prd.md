# 健身房会员管理系统需求说明书

适用对象：

用途：明确系统功能、流程、需求，作为开发、测试、验收依据。

## 一、项目概述

### 1.1 项目名称

瑜伽馆会员约课管理系统

### 1.2 系统使用角色

- 超级管理员（馆主/总负责人）
- 授课教练
- 会员（学员）

### 1.3 系统核心目标

1. 管理会员信息、购卡记录、卡项有效期、剩余次数。
2. 支持每周课表可视化编辑与发布。
3. 支持会员在线预约团课、签到、扣次。
4. 支持教练自主发布私教空闲时段，会员预约私教。
5. 实现数据统计、财务统计、约课记录统一管理。

### 1.4 系统运行端

1. PC 管理后台：电脑浏览器访问（管理员）。
2. 教练端：微信小程序 / H5 页面。
3. 会员端：微信小程序 / 公众号 H5。

## 二、会员管理模块需求

### 2.1 会员信息管理

1. 支持新增、编辑、查询、删除会员资料。
2. 字段包含：姓名、性别、手机号、生日、备注、入会日期、紧急联系人。
3. 支持会员状态管理：正常、停卡、到期、禁用。
4. 支持会员绑定多张卡项，自动关联约课权限。

### 2.2 会员记录查询

1. 查看会员所有购卡/续费/退款记录。
2. 查看会员所有团课、私教约课、签到、缺勤记录。
3. 查看卡项剩余次数、剩余天数、开卡时间、到期时间。

## 三、卡项管理模块需求（核心）

### 3.1 卡项类型设置

系统支持以下卡项类型，可自定义名称、价格、规则：

1. 期限卡：月卡、季卡、年卡。
2. 次数卡：通用团课次卡、专属课程次卡。
3. 私教卡：私教次数卡、私教套餐卡。
4. 体验卡：体验次卡、体验期限卡。

### 3.2 卡项核心字段

1. 卡项名称、售价、成本价（可选）。
2. 总次数/有效期天数。
3. 开卡方式：购卡即开卡 / 首次约课开卡。
4. 适用课程：团课 / 私教 / 指定课程。
5. 缺勤是否扣次、取消课程是否返还次数。

### 3.3 购卡/续费/开卡/停卡

1. 后台手动为会员办理购卡、续费、补卡、退款。
2. 支持卡项冻结、延期、解冻。
3. 自动计算到期时间、剩余次数、已用次数。
4. 卡项过期自动标记，支持提醒。

### 3.4 卡项核销规则

1. 约课成功后预扣次数/权限。
2. 签到后正式扣次。
3. 取消预约自动返还次数（按规则执行）。
4. 到期/无可用卡项无法约课。

## 四、团课管理模块需求

### 4.1 课程管理

1. 自定义课程类型：哈他、流瑜伽、阴瑜伽、普拉提等。
2. 设置课程时长、难度、简介、封面图。

### 4.2 课表编辑（后台核心功能）

1. 按周一至周日可视化编辑每周课表。
2. 可设置：时间段、课程名称、教练、教室、最大人数。
3. 支持复制上周课表、批量修改、临时调课。
4. 支持课程状态：正常、已满、取消、暂停。

### 4.3 会员团课约课

1. 会员查看课表 -> 选择课程 -> 在线预约。
2. 系统自动校验是否有有效卡项。
3. 人数满员后自动关闭预约，支持候补排队。
4. 限制：同一时间段仅可约 1 节课。
5. 可设置：提前 N 小时可约、课前 N 小时不可取消。

### 4.4 签到与核销

1. 支持二维码签到、手动签到、后台代签到。
2. 签到后自动扣次/扣期限。
3. 未签到自动标记为缺勤，按规则扣次。

## 五、私教课管理模块需求

### 5.1 教练信息管理

1. 教练资料：姓名、头像、擅长课程、简介。
2. 教练账号独立，仅查看自己相关数据。

### 5.2 教练空闲时间发布

1. 教练可在教练端设置可授课空闲时间段。
2. 支持按天/按周批量设置。
3. 可设置单次私教时长：60 分钟/90 分钟等。
4. 已被预约时段自动锁定，不可重复预约。

### 5.3 私教预约流程

1. 会员选择教练 -> 查看空闲时间 -> 提交预约。
2. 教练可确认/拒绝预约。
3. 预约成功后自动扣减私教次数。
4. 支持会员留言咨询私教时间。

### 5.4 私教签到与记录

1. 上课签到，生成上课记录。
2. 记录上课内容、课时消耗、会员状态。

## 六、权限与角色管理需求

### 6.1 超级管理员

- 全功能权限：会员、卡项、课表、财务、统计、员工管理。

### 6.2 教练

- 查看自己团课、私教课表。
- 发布私教空闲时间、签到、查看自己学员。
- 不可修改卡项、财务、其他教练数据。

### 6.4 会员

- 查看个人信息、卡项、约课、取消课、查看课表。
- 仅可操作本人账号。

## 七、消息提醒需求

1. 约课成功通知。
2. 课前 1-2 小时上课提醒。
3. 课程取消/调整通知。
4. 私教预约确认/拒绝通知。
5. 卡项到期、剩余次数不足提醒。
6. 支持微信服务通知/短信通知（可选）。

## 八、数据统计与报表需求

1. 会员统计：总会员数、活跃会员、即将到期会员。
2. 卡项统计：售卡数量、剩余次数、续费记录。
3. 课程统计：团课出勤率、满课率、课程热度。
4. 私教统计：教练上课数、课时消耗、完成率。
5. 财务统计：售卡收入、续费收入、退款金额。
6. 所有报表支持导出 Excel。

## 九、系统基础功能需求

1. 账号密码登录、权限分配、操作日志记录。
2. 数据自动备份，防止丢失。
3. 界面简洁、操作简单，适合非技术人员使用。
4. 支持手机号验证码登录（会员端）。
5. 支持约课记录、卡项记录长期保存。

## 十、验收标准（必备）

1. 可正常添加会员、办理卡项，准确记录次数与有效期。
2. 课表可自由编辑、复制上周、显示正常。
3. 会员可正常约课、取消课、签到，扣次准确。
4. 教练可发布私教时间，会员可预约私教。
5. 所有记录可查询、可统计、可导出。
6. 多角色权限区分清晰，无越权操作。
7. 系统运行稳定，无卡顿、无数据错误。
