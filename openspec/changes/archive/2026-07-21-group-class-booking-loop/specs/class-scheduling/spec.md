## ADDED Requirements

### Requirement: 管理真实团课课次
系统 MUST 允许管理员创建、编辑、发布、暂停、恢复、取消和完成团课课次，并保存课程、教练、教室、时间、容量及相对课前时长预约规则。

#### Scenario: 创建并发布课次
- **WHEN** 管理员创建信息完整且无资源冲突的课次并发布
- **THEN** 课次出现在对应周课表并可供预约

#### Scenario: 非草稿课次修改关键字段
- **WHEN** 管理员尝试直接修改已有预约课次的时间、课程、教练或教室
- **THEN** 系统拒绝修改并提示先取消或处理预约

#### Scenario: 复制课次保留相对规则
- **WHEN** 课次按周复制到新的日期
- **THEN** 新课次保留提前开放、停止预约和停止取消的相对时长配置

### Requirement: 周课表查询
系统 MUST 按自然周返回课次，并 MUST 根据有效预约数派生剩余名额和满员状态，同时返回课程、教练和教室名称。

#### Scenario: 查看指定周课表
- **WHEN** 用户查询给定周一开始的周课表
- **THEN** 系统按开始时间返回该周有权限查看的课次及容量信息

### Requirement: 复制上周排课
系统 MUST 允许管理员将源周除已取消外的课次复制到目标周，复制结果 MUST 为草稿且不得复制预约。

#### Scenario: 成功复制无冲突课次
- **WHEN** 管理员复制上周到空白目标周
- **THEN** 系统按七天偏移创建对应草稿课次且预约数为零

#### Scenario: 复制遇到资源冲突
- **WHEN** 目标周已存在教练或教室时间冲突
- **THEN** 系统跳过冲突项并返回可识别的冲突详情

### Requirement: 课次完成时间限制
系统 MUST 仅允许管理员在课次结束时间到达后完成课次。

#### Scenario: 提前完成课次
- **WHEN** 管理员在课次结束前请求完成
- **THEN** 系统拒绝状态迁移且课次保持原状态

### Requirement: 取消课次处理预约权益
系统 MUST 在取消课次时取消全部未终结预约，并通过取消核销终态按卡项规则处理权益。

#### Scenario: 取消存在预约的课次
- **WHEN** 管理员取消包含有效预约的课次
- **THEN** 所有预约被取消、核销链路终结且课次不再接受预约
