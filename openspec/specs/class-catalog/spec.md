# class-catalog Specification

## Purpose
定义团课课程、教室和教练基础资料的管理与读取权限，以及排课引用、教室容量和指定课程卡项适用性的业务约束。

## Requirements

### Requirement: 管理团课基础资料
系统 MUST 允许管理员创建、编辑、查询和停用课程、教室及教练资料，并 MUST 拒绝普通会员执行这些操作。

系统 MUST 允许所有已登录角色读取课程、教室和教练资料，但写操作 MUST 仅允许管理员执行。

#### Scenario: 管理员创建完整课程资料
- **WHEN** 管理员提交课程名称、时长、难度、简介和启用状态
- **THEN** 系统保存课程并允许后续排课引用

#### Scenario: 会员修改基础资料被拒绝
- **WHEN** 会员尝试创建、编辑或停用课程、教室或教练
- **THEN** 系统返回 403 并记录拒绝审计

#### Scenario: 会员读取基础资料
- **WHEN** 已登录会员查询启用的课程、教室或教练
- **THEN** 系统返回可用于课表展示的基础资料

### Requirement: 排课引用有效基础资料
系统 MUST 仅允许课次引用存在且启用的课程、教室和教练，且课次容量 MUST 不超过教室容量。

#### Scenario: 使用停用课程排课
- **WHEN** 管理员使用已停用课程创建课次
- **THEN** 系统拒绝创建且不产生课次

#### Scenario: 课次容量超过教室容量
- **WHEN** 管理员设置的课次容量大于教室容量
- **THEN** 系统返回业务校验错误

### Requirement: 指定课程卡项使用真实课程标识
系统 MUST 在保存指定课程卡项时校验课程标识，并 MUST 在预约时验证卡项适用于目标课程。

#### Scenario: 使用不适用卡项预约
- **WHEN** 会员只有不包含目标课程的指定课程卡项
- **THEN** 系统拒绝预约且不创建预扣事件
